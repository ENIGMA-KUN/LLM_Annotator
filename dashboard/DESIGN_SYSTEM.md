# Design system: Apple craft, ASU brand

> Apple's rules govern structure, type, motion and materials.
> ASU brand governs colour. Where they meet, brand picks the hue and Apple decides how it
> is applied.
>
> Adapted from Emil Kowalski's notes on Apple's interface design:
> https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md

---

## Colour

Taken from the ASU Learning Engineering Institute site.

| Token | Value | Use |
|---|---|---|
| `asu-maroon` | `#8C1D40` | Primary identity, primary action, active nav |
| `asu-maroon-dark` | `#6B1531` | Pressed state, dark surfaces |
| `asu-gold` | `#FFC627` | Accent. Highlight blocks, rules, emphasis |
| `asu-black` | `#000000` | Structural dark regions, as on the LEI Values band |
| `asu-gray-*` | `#FAFAFA` to `#191919` | Neutrals carry the interface |

Two rules that are not negotiable.

1. Never gold text on white. ASU gold on white is roughly 1.7:1 contrast and fails WCAG
   badly. Gold is a *background* with black text on top, exactly how the LEI site uses it,
   or a rule/underline. This is the single easiest way to make an ASU-themed interface look
   wrong and be inaccessible at the same time.
2. Maroon is not a background for body text at scale. Use it for identity, small
   emphasis, and primary buttons with white text. Large maroon fills behind paragraphs read
   as heavy and reduce legibility.

Colour marks meaning, never decoration. Data status keeps its own semantic scale (emerald /
amber / rose) because those encode result quality, not brand.

## Typography

System font stack. Apple's point: the platform font already ships optical sizing, tracking
tables and legibility tuning. Override only with a reason.

Tracking is size-specific. A single `letter-spacing` value is wrong somewhere.

| Class | Size | Leading | Tracking |
|---|---|---|---|
| `.type-display` | `clamp(1.75rem, 3vw, 2.5rem)` | 1.05 | `-0.022em` |
| `.type-title` | `1.25rem` | 1.2 | `-0.015em` |
| `.type-heading` | `1rem` | 1.3 | `-0.01em` |
| body | `0.9375rem` | 1.55 | `0` |
| `.type-caption` | `0.75rem` | 1.4 | `+0.005em` |
| `.type-mono` | tabular numerals | 1.4 | `-0.01em` |

Hierarchy comes from weight + size + leading as a set, not size alone.

All spacing in `rem`, so a user's larger text setting scales the layout with it rather than
breaking it.

## Materials

Translucent chrome with content scrolling underneath, not opaque bars consuming a strip.

```css
.material-chrome {
  background: rgba(255, 255, 255, 0.72);
  backdrop-filter: blur(20px) saturate(180%);
}
```

Material weight encodes hierarchy: heavier for structural regions, lighter for interactive
elements. A light translucent surface is never stacked on another, because legibility
collapses. Bigger surfaces read as thicker: stronger blur, deeper shadow.

Scroll edge effects instead of 1px dividers, only where floating chrome actually overlaps
content.

## Motion

Springs, expressed as CSS easing. Honest limitation: no spring library is installed, so
these are cubic-bezier approximations. They are not interruptible or velocity-aware. That is
acceptable here because this dashboard has no drag or swipe gestures. If a gesture is ever
added, install Motion and use real springs. CSS transitions cannot be grabbed and
reversed mid-flight, which is Apple's most important principle.

| Token | Curve | Use |
|---|---|---|
| `--ease-standard` | `cubic-bezier(0.32, 0.72, 0, 1)` | Default. Critically damped feel |
| `--ease-momentum` | `cubic-bezier(0.34, 1.36, 0.64, 1)` | Slight overshoot, only after a momentum-carrying action |
| `--dur-fast` | `120ms` | Press feedback |
| `--dur-base` | `260ms` | Standard transition |

Feedback fires on pointer-down, not release: `:active { transform: scale(0.98) }`.

Only `transform` and `opacity` are animated, so everything stays on the compositor.

## Accessibility

Three independent signals, all handled in `index.css`:

- `prefers-reduced-motion: reduce`: transforms removed, short opacity cross-fades kept.
- `prefers-reduced-transparency: reduce`: translucent surfaces become solid, blur dropped.
- `prefers-contrast: more`: near-solid backgrounds with defined borders.

Focus rings are visible and use maroon, never removed.
